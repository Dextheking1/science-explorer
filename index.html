1. Your Pollen key

Bring your own Pollen. Paste a Pollinations secret key (sk_...) below. The key is stored only in this browser, in localStorage, and requests go only to gen.pollinations.ai. No key? The app runs in demo mode with a clearly labelled built-in sample on photosynthesis.

Get a key at enter.pollinations.ai. One explainer is one chat call, each dive is one more, and the diagram is one image call.

2. Pick a topic

How exploring works

  • The model returns a strict JSON explainer: key ideas, a step by step mechanism, common misconceptions, 3 questions.
  • A reply that is not valid JSON gets exactly one repair retry, then an error. Nothing half parsed is shown.
  • Every idea, step, misconception and question is clickable. A click makes a second call with that part as context.
  • Each dive ends with a check question, so reading turns into testing yourself.
  • The diagram is fetched with your key in the header, never in the URL.
